Kammflug — Low-Poly-Flug über Madeira

Dieses Paket ist der Quelltext der Simulation.

Messdaten, nur im Kreis von 32 km um die Insel:
- Höhen: offene Terrarium-Kacheln (EU-DEM, GMTED). Kacheln außerhalb antworten mit 403.
- Wetter: Open-Meteo, CC BY 4.0, fünf Punkte (Mitte, Nord, Ost, Süd, West).
  Andere Koordinaten werden abgelehnt. Abgerufen wird nie die ganze Erde.

Im Flug:
- Wind schiebt das Flugzeug nur in der Luft, inklusive Böen.
- Wolkenzug, Bewölkung und Sicht folgen der Messung.
- Regen oder Schnee erscheint, wenn die Stationen Niederschlag melden.
- HUD: Höhe, Kurs, Schub, Temperatur, Wind, Böen, Sicht.

Steuerung:
Maus Blick, W/S Schub, A/D Ruder (A links), Q/E oder Pfeile Nase,
Leertaste / Strg steigen und sinken, F Drahtmodell, N Tag/Nacht.
Auf dem Touchscreen: Stick und Hoch/Runter.

Quellen:
Open-Meteo https://open-meteo.com/
AWS Open Data Terrain Tiles (Terrarium)
